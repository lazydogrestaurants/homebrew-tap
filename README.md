# homebrew-tap

Homebrew formulae for Lazy Dog utilities, kept up to date by
[Conservatory](https://conservatory.ldeat.com).

## Installing a utility

The formulae download from Lazy Dog's Azure Blob Storage with your Lazy Dog Microsoft account, which
Homebrew gets from the Azure CLI. Once per Mac:

1. Install the Azure CLI:

   ```sh
   brew install azure-cli
   ```

2. Sign in with your Lazy Dog account:

   ```sh
   az login
   ```

Then install a utility by its full name, which is on its Conservatory page:

```sh
brew install lazydogrestaurants/tap/<formula>
```

`brew upgrade` keeps it up to date. Installing by the full name trusts just that formula (see
Homebrew's [Tap Trust](https://docs.brew.sh/Tap-Trust)), so install each utility that way.

If a download fails with "The Azure CLI couldn't get a token", your Azure CLI sign-in has expired
or was never made: run `az login` again, then retry the `brew` command.

## What's in this repository

- `Formula/`: one formula per utility. Conservatory generates these files and commits them whenever
  a version is published, so **don't edit them**: a formula's first line is
  `# Generated by Conservatory. Don't edit: changes are overwritten.`, and Conservatory replaces or
  deletes any file that starts with it. To change a formula, change the utility in Conservatory.
- `lib/entra_blob_download_strategy.rb`: the download strategy every formula uses. It gets a Blob
  Storage token from the Azure CLI when Homebrew downloads, and it keeps an archive's lone
  top-level directory when Homebrew unpacks it, so a formula's executable path is relative to the
  archive root. It overrides Homebrew internals, so check it against Homebrew's source when
  Homebrew changes them (the comments name the methods and the Homebrew version last checked).

Changes to anything outside `Formula/` go through pull requests.
